# 🚀 Task Management System

A modern and responsive Task Management System built with **Laravel 10**, **Laravel Breeze**, and **Tailwind CSS**.

This project allows authenticated users to efficiently manage their daily tasks with a clean dashboard and premium responsive user interface.

---

# ✨ Features

- 🔐 User Authentication (Laravel Breeze)
- 📊 Dashboard with Task Statistics
- ➕ Create New Task
- 👀 View Task Details
- ✏️ Edit Existing Task
- 🗑 Delete Task
- 🔍 Search Tasks
- 🎯 Filter Tasks by Status
- 📄 Pagination
- 📱 Fully Responsive Design
- 🎨 Modern Premium UI
- ⚡ Repository Pattern
- ⚙️ Service Layer Architecture

# ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/rizzwan327-source/task-management-system.git
```

Move into project

```bash
cd task-management-system
```

Install Composer Packages

```bash
composer install
```

Install NPM Packages

```bash
npm install
```

Copy Environment File

```bash
cp .env.example .env
```

Generate Application Key

```bash
php artisan key:generate
```

Configure Database inside `.env`

Run Migration

```bash
php artisan migrate
```

Run Development Server

```bash
npm run dev
```

```bash
php artisan serve
```
